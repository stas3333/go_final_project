# Файлы для итогового задания

В этом проекте реализован планировщик задач.
В нём написаны: веб-сервер, работа с REST API и базами данных.

API содержит следующие операции:
-добавить задачу;
-получить список задач;
-удалить задачу;
-получить параметры задачи;
-изменить параметры задачи;
-отметить задачу как выполненную.

Список выполненных задач со звездочкой:

- Реализованы переменные окружения:
  - TODO_PORT
  - TODO_DBFILE
- Создан DOCKERFILE

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Проект запускается с терминала командой `go run .` в дерриктории проекта.

После чего, можно во втором терминале запустить все тесты разом, командой `go test ./tests`

Либо перейти на сайт планировщика, введя в адресной строке браузера путь http://localhost:7540

Инструкция по сборке и запуску контейнера находится в `DOCKERFILE`.
